# Mirror Match 🪞

The 10-second copy battle for iPhone. Watch a move, copy it faster and more precisely than your opponent.

- **Quick Duel** – best of 5 vs an AI ghost, rank ladder (Rookie → Legend)
- **Daily Challenge** – same 5 moves for everybody, streaks, Wordle-style share
- **Challenge a Friend** – serverless: seed + score travel inside a link
- **Face to Face** – real-time split-screen on one phone
- **Custom Moves** – draw a move, share it as a link
- **Replay videos** – rendered locally (AVAssetWriter), 9:16, ready for TikTok/Reels
- **Monetization** – Mirror Match Pro (weekly/yearly subscription), ticket packs (consumable), skin pack (non-consumable)

SwiftUI · StoreKit 2 · no backend · no tracking.

## Build
```sh
brew install xcodegen
xcodegen generate
open MirrorMatch.xcodeproj
```
`docs/` is the GitHub Pages site (landing, privacy, support, challenge link landing page).
